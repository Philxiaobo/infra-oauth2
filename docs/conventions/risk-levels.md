# 变更风险等级

本文件定义改动风险等级。风险越高,Codex 应扩大检索范围、补充验证、必要时先写 ADR。

## 等级

| 等级 | 范围 | 处理要求 |
|------|------|----------|
| P0 | 资金、账户余额、权限、安全、数据迁移、支付/清结算、生产配置 | 必须有 spec;必要时 ADR;必须记录验证和回滚思路 |
| P1 | 核心业务链路、对外 API、消息事件、任务调度、数据一致性 | 必须有 spec;至少跑相关测试或说明无法验证 |
| P2 | 普通业务功能、内部管理流程、非核心配置 | 建议有 spec;运行最小相关验证 |
| P3 | 文案、样式、小范围重构、低风险脚本 | 可不建 spec;仍需 WORKLOG 记录 |

## 默认升级规则

- 涉及删除数据、批量更新、权限放开:至少 P0
- 涉及外部系统契约:至少 P1
- 涉及跨模块公共方法:至少 P1
- 用户报告线上故障:至少 P1,资金/权限相关升 P0

## Codex 执行要求

- P0/P1 改动前先明确范围和非目标
- P0/P1 改动后必须执行 `session-close`
- 无法运行验证时,必须写清原因和替代检查
